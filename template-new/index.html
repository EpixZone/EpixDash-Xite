Welcome to Your New Xite

This xite is hosted on EpixNet, a decentralized, peer-to-peer web.

Getting Started

This is your xite's index.html file. Everything you see here can be edited to make it your own.

  • Your xite's files are in your EpixNet data folder, in the data/ folder named after this xite's address. Edit them with any text editor.
  • Edit index.html to change this page, and add your own images, CSS, and JavaScript files next to it
  • Open the sidebar by dragging the round button at the top right of the page to the left
  • Click Sign and publish in the sidebar to push your changes to the network

How EpixNet Xites Work

  • No web server needed: your EpixNet node serves your xite directly to peers
  • Your private key is kept on your node and proves you own this xite
  • content.json lists every file with its size and hash, and is updated automatically when you sign
  • Peers who visit your xite keep a copy and help serve it to others
As long as your EpixNet node is running, your xite is being served to peers. The more visitors, the more available your xite becomes.

Example: Adding Content

EpixNet xites are standard HTML, CSS, and JavaScript. Here's a simple example:

Using the EpixNet API

Your xite can talk to your EpixNet node through the EpixFrame library, which is included in this xite as js/lib/epixframe.min.js. This page uses it:

<script src="js/lib/epixframe.min.js"></script>
<script>
// Connect to the EpixNet wrapper
var page = new EpixFrame()

// Commands work once the wrapper's connection to the node is open
page.on("openWebsocket", function () {
  page.cmd("siteInfo", {}, function (info) {
    console.log("Xite address:", info.address)
    console.log("Peers:", info.peers)
  })

  // Show a notification
  page.cmd("wrapperNotification",
    ["info", "Hello from my xite!", 5000])
})
</script>

Live from your node: this xite is with peers.

The EpixFrame API lets you read and write files, query the xite's database, manage users, and more. Check the docs for the full API reference.

Tips

  • Each xite can use up to 1000 MB on a visitor's node by default, and visitors can raise the limit from the sidebar
  • The sidebar's Browse files button lists your xite's files and can revert a changed file to its last signed version
  • After making changes, always Sign and publish to update the network
  • If you own an xID name (like mysite.epix), enter it in the sidebar for a human-readable address
